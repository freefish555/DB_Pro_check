# 补充开发验收记录

本次沿用 FastAPI、SQLite、React 及既有依赖，未新增运行依赖。真实报告、参考工作簿、运行数据和密钥不进入仓库。

## 功能与证据

| 范围 | 实现 | 验证 |
| --- | --- | --- |
| 全文预处理 | 正文顺序块、层级章节、目录隔离、文档版本引用、嵌套表索引及复杂内容诊断 | 合成 DOCX 测试；网页展开章节段落与表格 |
| 关键信息 | 字段三文档并排、主体归属、候选出处、空值/缺失/失败/同文档冲突、独有信息展开 | 字段和数量测试；网页缺失状态核对 |
| 十二类数量 | 有效来源条目、全对象/抽选、重要程度、重复和异常 | 合成表格测试，不以台/套列求和 |
| 三文档一致性 | 对象并集、报告基准、缺失计差异、逐来源标色、横向 Excel 汇总及逐字段证据 | 比较和 API 导出测试 |
| 章节问题 | 相关章节共用问题 ID、版本校验、原子批量复核、当前运行导出及覆盖状态 | API/前端测试；网页章节切换与原文查看 |
| 高风险 | 原脚本98阈值、13列专业表、连续风险单元格合并 | 合成边界与导出测试；此前本地案例逐格核对 |
| 附录D | 常规基本语义一致、严格全覆盖；两档文字及符合判断检查；14列专业视图 | 请求契约、分类和专业导出测试 |
| 脱敏 | 结构化敏感值、项目词典、上下文待核实、逐条预览补充、请求哈希授权、最终出口复查 | 合成请求体、未知字段、变更授权及阻断测试 |
| 个人模型 | 用户私有配置和Key、项目团队权限 | 已有个人模型和API权限测试 |

独立审查后的修复：无运行也可查看已上传报告原文；同类型电话不同值标冲突；切换项目清空问题/详情并拒绝旧项目异步回填；嵌套表不覆盖外层原文；全文与附录D覆盖状态分别判断；问题保留规则版本。

## 验证范围与限制

完整后端测试、前端 Node 测试、TypeScript/Vite 构建及 Git 差异格式检查分别运行。最终计数以发布说明中的最新输出为准。

浏览器已核对关键信息缺失状态、章节入口、顺序原文和已确认问题计数。问题汇总下载请求返回200；浏览器自动化的下载事件未捕获，因此不将它记录为完整下载验收。导出内容由API测试读取XLSX/DOCX核验。

未向外部真实模型发送项目材料；模型请求和回复按合成契约测试。图片/文本框保留引用与诊断，不提供OCR保证。任意自由文本敏感身份信息无法仅靠固定规则保证全部识别，必须逐条检查脱敏预览并补齐词典。规则待配置、未运行、提取失败均不代表审核通过。

当前发布为可审查的功能分支，正式使用前应按README启动并用审核人员熟悉的材料验收。现有正式数据库升级前先备份。
